# Hire.com: From Tester to Team Lead

**Quality Engineering Team Lead** — Oct 2000 to May 2004

## The Role

Started as a tester and was promoted to QE team lead. Ended up running a team of 4 permanent engineers plus up to 5 contractors (including an offshore team in Pune, India) and up to 12 interns. Managed priorities across 5 product lines and their maintenance releases.

This was my first real exposure to distributed teams, offshore coordination, and juggling multiple simultaneous release cycles.

## What I Did

- White/black box testing of web-based enterprise software on Java/JSP/Linux with Oracle 8i/9i RAC backend
- White/black box testing of web-based enterprise software on .NET/C#/Windows 2000/2003 Server with SQL Server 2000 backend
- Black box testing of WebMethods server and Crystal Reports products
- Developed test plans, test cases, and approach using IEEE standardized test documentation
- Designed and executed test scripts, including automation using VB, VBScript, and VBA
- Started the RSW eTest user group in Austin and got the company to sponsor it

## Tools

RSW eTest, SilkTest, Oracle 8i/9i, SQL Server 2000, Linux, Windows 2000/2003 Server.
